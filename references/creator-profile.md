# 立正的偏好：复用时替换这一层

这份 Skill 从立正的单人口播实践中提炼而来。下面是制作偏好与公开入口，**不是登录凭据，也不是发布许可**。当前任务、账号所有者和工作区指令优先。别人的口播风格、平台、账号与审批方式应使用自己的配置。

## 个人流程

- 自然录完一遍，后期精校字幕，只剪明显说错、重复和废弃重说，不为完成后期强制补录。想练表达的人可以主动开启录前辅导或下一次建议。
- 普通口播默认竖屏；原生横屏、长视频按本期要求处理。字幕避开平台信息层、不挡脸，按实际画面放。
- 画面要帮观点更容易懂、更容易记住。2026-10-07 立正在一条 22 分钟的竖屏口播上明确要过目录、进度条、章节标题和要点图示；长视频默认考虑这类定位工具。克制指的是不堆装饰，不是少放帮助理解的画面。
- 封面选自然真人帧，字少而清楚。立正给过一组三列网格的外部封面做参考，方向是“一个能认出的话题 ＋ 一句本期的判断”，补句要推进同一个意思；这是可以尝试的方向，不是固定版式。
- 默认交付成片、字幕、封面、发布文案，工程留在所属视频项目。“剪一下／剪好／做出来”不包括审阅网站、剪辑对照页、本地预览服务或衍生文章。新项目用当前视频库的 README 确认位置，目录按录制日期与主题命名。不要把旧路径写死在工具里。
- 默认准备 YouTube「课代表立正」、Instagram `@lizheng.ai` 与已确认的 Google Drive 主目录。常规排期是西雅图每天 17:00；时效性视频按本期明确要求。小红书需要本批指定。
- 国内分发有时交给会客厅／切片号，课程、活动等也可能用主号。本期账号映射单独记录，不能把“非 YouTube”全部自动归给切片号。

## 口播提到这些时，画面里放什么

- 提课程：放 [AI Builders](https://ai-builders.com/) 上对应课程或真实成果的页面，画面里能看清 `ai-builders.com`，并且给够看清楚的时间。不要拿不相关的页面填空。
- 讲社区、Skill 帖、回放或评论：放对应的真实页面。适合本期时，可以说明下载「超线性学院」App 能看免费内容；具体内容是否开放要核对，不能把会员内容说成全部免费。评论多的场景，可以用多张真实截图分批出现。
- 指着身上的 swag：保留这个动作和画面。发布时只放核对过的同款商品。
- 讲书或带货：保留内容本身需要的书和结果画面。国内商品组件和 YouTube／IG 的原生商品标签是两种能力，要分开核对。
- 一次性的情况（比如“刚健身完，一身汗”、车内录制的支架和地点）只按本期确认的事实处理，不推广成以后每条的固定提示。
- 封面：YouTube 和 Instagram 准备 9:16；小红书在本批要求时另做 3:4。
