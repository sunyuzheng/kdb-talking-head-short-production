这份 Skill 从立正的单人口播实践中提炼而来。下面是制作偏好与公开入口，**不是登录凭据，也不是发布许可**。当前任务、账号所有者和工作区指令优先。别人的口播风格、平台、账号与审批方式应使用自己的配置。

## 个人流程

- 自然录完，后期精校字幕、剪掉明显废话与废弃重说；不为完成后期强制补录。想练表达的人可以主动开启录前辅导或下一次建议。
- 普通口播默认竖屏，原生横屏按本期要求处理；字幕在中下部避开平台信息层，封面选自然真人帧，少字且清楚。
- 图解与真实素材按理解需要添加；不要求每条都用 HyperFrames、B-roll 或复杂动画。
- 默认交付成片、字幕、封面、发布文案；工程留在所属视频项目。新项目使用当前视频库的 README 确认位置，目录按录制日期与主题命名。不要把旧路径写死在工具里。
- 默认准备 YouTube「课代表立正」、Instagram `@lizheng.ai` 与已确认的 Google Drive 主目录。常规排期是西雅图每天 17:00；时效性视频按本期明确要求。小红书需要本批指定。
- 国内分发有时交给会客厅／切片号，课程、活动等也可能用主号。本期账号映射单独记录，不能把“非 YouTube”全部自动归给切片号。
